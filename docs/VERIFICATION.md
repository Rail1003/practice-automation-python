## Ограничения среды

Среда подготовки — Linux-контейнер. Chrome for Testing и Firefox с драйверами
загружены, но локальная браузерная сессия не запускается. Для Chrome исследование
запуска показало отказ системного вызова `socket(): Operation not permitted`;
запуск Firefox через WebDriver вернул `Failed to decode response from marionette`.
Доставляемая фикстура не добавляет небезопасных Chrome-флагов для обхода среды.

Поэтому утверждать, что все 72 UI-теста прошли, нельзя. Windows, PowerShell-скрипты,
GitHub Actions и полный прогон Chrome / Firefox требуют выполнения в целевой среде.
Сценарии настроены для такого запуска; README содержит прямые команды и скрипты.
При ошибке WebDriver до создания сессии PNG-скриншот недоступен; Allure сохраняет
ошибку и объяснение вместо вымышленного вложения.

В диагностическом Allure-отчёте находятся **два Broken**, а не результаты всего
набора и не подтверждение успешности. Он включён как проверка формирования отчёта
и как воспроизводимое свидетельство ограничения среды.
